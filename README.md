# Dennis William - Portfolio Website

This repository contains the source code for my personal portfolio website. It serves as a central hub to showcase my academic background, technical skills, projects, and professional experience. The site includes sections for an about me summary, services offered, a project showcase, and a contact form.

## Technology Stack

This project is built using the following technologies:

- **Framework:** Next.js
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** React Icons, Lucide React
- **Animations:** Animate.css, Tailwind Animate
- **Form Handling:** EmailJS
